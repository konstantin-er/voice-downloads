# Voice для Mac

Готовое приложение и инструкция по установке находятся в [Releases](https://github.com/konstantin-er/voice-downloads/releases).

Voice записывает речь, распознаёт её локально и вставляет текст в активное поле. Необязательная обработка текста через OpenAI-совместимый сервис настраивается отдельно.

Для установки скачайте `Voice.zip` и `Voice-install-guide.pdf` из последнего релиза. Автоматические архивы исходного кода GitHub не содержат приложение.
